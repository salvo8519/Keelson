# Impostazioni

Tutte le impostazioni del backend (`app/core/config.py`), lette dall'ambiente o da
`backend/.env`, generate dal codice a ogni build di questo sito. Segreti e credenziali non hanno
un valore predefinito pubblicato: vanno impostati nell'ambiente. `backend/.env.example` elenca
quelli da impostare per primi.
