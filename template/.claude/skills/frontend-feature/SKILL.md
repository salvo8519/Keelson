# Frontend Feature (React, Vite, TanStack)

The frontend lives in `frontend/src/`: file routes with TanStack Router, data with TanStack
Query, components from shadcn/ui, strings translated with i18next.

## Steps

1. **API first.** Add or change the backend endpoint, then run `make client`: it writes the
   API contract and regenerates `src/client/` from it. Never edit `src/client/` by hand.
2. **Route.** Add `src/routes/_layout/<feature>.tsx` for a signed-in page (the layout checks
   the session) with `createFileRoute("/_layout/<feature>")`. The route tree
   (`src/routeTree.gen.ts`) is regenerated by the Vite plugin on `bun dev` or `bun run build`.
3. **Data.** Use the generated service with `useQuery` / `useMutation`; invalidate the
   affected query keys on success; report errors with `handleError` and the toast hook.
4. **Components.** Put feature components in `src/components/<Feature>/`; build them from
   `src/components/ui/`. Add a sidebar entry in `src/components/Sidebar/` if the page needs one.
5. **Text.** Wrap every visible string in `t("...")` and add its Italian translation to
   `src/locales/it.json`. `bun run i18n:check` fails on a missing one.
6. **Check.** `bun run lint`, `bun run i18n:check`, `bun run build`.

## Rules

- Organization scoping is automatic (`X-Organization-Id` from `src/lib/session.ts`).
- No third-party scripts, fonts or images: the Content Security Policy blocks them.
- No decorative icons; short, plain labels.
