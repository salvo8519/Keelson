Refresh tokens are rotated with reuse detection, atomically and on the clock of Redis so that replicas cannot disagree, and signing out ends every token of the session; an impersonation ends when its administrator loses the role or signs out everywhere; a present `Origin` header (`null` included) decides alone on cookie requests; a refresh token expired by the clock of Redis is refused, and its keys outlive it by a clock skew margin; the session version and the magic-link epoch can no longer decrease; a sign-in, reset or address change link redeemed twice at the same moment works once; an address change link cannot be replayed after the address changed back. The welcome e-mail and the notice of a registration with a known address leave after the commit and the response, so a failed registration sends nothing; `GET /users/me` no longer reads the password hash to tell whether the account has one; password hashing in account creation and changes no longer blocks the event loop. The account deletion dialog and the profile form no longer keep the typed password after an attempt or after closing; refused API keys stay audited at most once a minute per key while Redis is down.
