Sessions end when they should: a password change, a password reset, a password set by an administrator, a deactivation and the new sign-out from every device end every earlier session, and signing out ends that session's refresh token. Existing tokens are refused once after the upgrade, so every user signs in again. Access tokens may last at most 60 minutes in staging and production. Sign-in is protected against login CSRF, session refreshes have their own per-user limit, registration no longer tells whether an address has an account (it answers 202 Accepted), impersonation is attributed to the administrator, avatars are served to members of a shared organization, and uploaded files are served sandboxed with RFC 6266 file names.
